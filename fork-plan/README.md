## Главные выводы разведки

1. **Клик по курсору уже есть в режиме Blocks** (новая вкладка: Cmd+Shift+T). Там строка ввода на CodeMirror: клик ставит курсор, выделение мышью, Cmd+Z, автоподсказки из истории. Не включён по умолчанию. Для обычных вкладок клика нет: нужен перевод клика в стрелки по меткам OSC 133 (только JS, без пересборки WASM).
2. **HTML-превью**: правильный путь это свой протокол `terax-preview://` в Rust плюс iframe без `allow-same-origin`. Вариант через `asset://` опасен (scope `**`, скрипт страницы прочитает `~/.ssh`), `srcdoc` с same-origin даёт странице доступ к IPC приложения.
3. **SSH**: автор апстрима закрывает все SSH PR и делает SSH сам, поэтому держим код в отдельных модулях. Рекомендуемый подход: системный `ssh -tt` внутри обычного PTY (работает твой `~/.ssh/config` с Include OrbStack, агент, ProxyJump, 2FA), ControlMaster для повторного использования соединения, SFTP через `russh-sftp` поверх `ssh -s sftp` (+167 KB к бинарю), поиск через exec (совместимо и с GNU, и с BSD, потому что iMac тоже удалённая машина). Тот же механизм даст Blocks и клик по курсору на сервере.
4. **Ловушки форка**: встроенный автоапдейтер поставит апстрим-релиз поверх форка; одинаковый bundle id с установленным Terax 0.8.6 (общие настройки, keychain `terax-ai`, `~/Library/Caches/terax/control.json`).
5. **Сборка работает**: lint 0 ошибок / 90 предупреждений, check-types чисто, vitest 1209 тестов, cargo clippy чисто, cargo test 373. Бюджет JS почти исчерпан (1.47 из 1.5 MB gzip), всё новое только lazy.

## Как продолжить

Окружение для любых команд node/pnpm/cargo:

```bash
source fork-plan/tools/env.sh
```

Реализация: попроси Claude запустить волну W0 из PLAN.md (протокол выполнения в разделе 3 плана).

Запуск приложения в dev, не трогая установленный Terax:

```bash
pnpm tauri dev --config '{"identifier":"app.crynta.terax.dev"}'
```

Остановка dev-бинаря только по пути: `pkill -f target/debug/terax` (не `pkill -x terax`, иначе закроется твой основной Terax).

Папка `fork-plan/` не в git (untracked). Не коммить её в ветки фич случайно.
