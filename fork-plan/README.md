# План и исследование личного форка Terax

Эта папка хранит исходный план от 2026-10-09, карточки задач и исследование кодовой базы на ревизии `3301de2`. Она отслеживается в Git и нужна для контекста принятых решений.

Реализация уже ведётся: в форке есть SSH-пространства, HTML-превью, улучшения терминала и редактора. Старые отчёты и карточки описывают состояние на момент планирования. По ним нельзя определять текущую готовность функции или повторно запускать все волны с W0.

Текущее устройство описано в [TERAX.md](../TERAX.md), правила разработки в [FORK.md](../FORK.md), возможности и проверки в [гиде по форку](../docs/fork/README.md). Историю изменений смотри в `git log fork/main`.

## Как продолжать работу

1. Найти нужную карточку в [PLAN.md](PLAN.md) и проверить по коду и истории, какие её части уже выполнены.
2. Сверить решение с текущей архитектурой и правилами в `TERAX.md` и `FORK.md`.
3. Создать ветку задачи от `fork/main`, выполнить изменение и подходящие проверки.

Для текущей разработки используется окружение из `scripts/fork/`, а доступные команды перечислены в [scripts/README.md](../scripts/README.md):

```bash
source scripts/fork/agent-env.sh
pnpm fork:dev
```

Сценарии в `workflows/` содержат привязки к исходному окружению и моделям. Перед повторным использованием их нужно сверить с текущими правилами; обычный запуск и сборка через них не проходят.
