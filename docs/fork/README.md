# Terax: гид по личному форку

Terax объединяет терминал, редактор, проводник, Git, предпросмотр и ИИ. В форке добавлены SSH-пространства, удалённые файлы, HTML-превью и улучшения работы с терминалом. Описание возможностей и установка находятся в [главном README](../../README.md).

## Быстрый запуск

Из корня репозитория:

```bash
source scripts/fork/agent-env.sh
pnpm install --frozen-lockfile
pnpm fork:dev
```

Для сборки приложения и DMG: `pnpm fork:release`. Результат появляется в `release/`. Флаг `-- --install` также устанавливает сборку в `/Applications`. Подробности команд: [scripts/README.md](../../scripts/README.md).

## Что важно в повседневной работе

- В запуске агентов по умолчанию выбран один экземпляр. При необходимости можно выбрать от двух до четырёх.
- Обычный клик по ссылке в выводе терминала открывает системный браузер. В редактируемой строке команды ссылка открывается по Cmd/Ctrl+клику, обычный клик перемещает курсор.
- Режим новой вкладки, Classic или Blocks, выбирается в настройках. Cmd+T открывает выбранный режим, Cmd+Shift+T открывает другой.
- Встроенный ИИ использует твои API-ключи или локальную модель. Claude Code, Codex и другие CLI-агенты в терминале работают как отдельные программы.
- У форка отдельный идентификатор `dev.terax.fork`. Встроенное автообновление отключено; новую сборку нужно устанавливать вручную.

## Как понимать размеры

`pnpm size` проверяет бюджеты из [.size-limit.mjs](../../.size-limit.mjs). Для всех JavaScript-модулей клиента порог составляет 1505 KB gzip, для стартового JavaScript каждого окна 540 KB gzip. Остальные пороги и способ расчёта описаны в [устройстве приложения и лимитах](size-and-architecture.md).

Это контроль роста сборки. При превышении падает проверка, а запущенное приложение продолжает работать. Размер `.app`, размер сжатого DMG, объём папки проекта и расход RAM измеряются отдельно. Например, `node_modules/` и `src-tauri/target/` нужны для разработки и не копируются целиком в установленное приложение.
